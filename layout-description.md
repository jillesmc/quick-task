# Layout do Formulário - Descrição Hierárquica

## Grid Layout Principal

- **Summary**
  - Linha 1: Label "Summary:"
  - Linha 2: Campo de texto (TextField)

- **Description**
  - Linha 1: Label "Description:"
  - Linha 2: Campo de texto (TextArea)

- **Linha com 2 colunas**
  - **Coluna 1** (largura: 500px)
    - Tipo de atividade
      - Label "Tipo de atividade:"
      - Radio buttons com as opções
  
  - **Coluna 2** (largura: 250px)
    - **Linha 1**: Documentação anexa
      - Label "Documentação anexa:"
      - Radio buttons (Sim/Não)
    - **Linha 2**: Utilização de IA
      - Label "Utilização de IA:"
      - Radio buttons (Sim/Não)

- **Linha com 2 colunas**
  - **Coluna 1** (largura: 500px)
    - Status
      - Label "Status inicial:"
      - Radio buttons com as opções
  
  - **Coluna 2** (largura: 250px)
    - Worklog
      - Label "Worklog:"
      - Checkbox "Registrar worklog"
      - Campos de worklog (quando checkbox marcado)
